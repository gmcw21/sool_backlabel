🚀 GitHub에 업로드 및 index.html 업데이트 방법

이 웹페이지는 별도의 서버나 라이브러리 설치 없이 단 하나의 파일(index.html)로 작동합니다. 이미 GitHub 저장소를 만드신 경우 기존 index.html 파일에 덮어쓰기만 하시면 즉시 새 버전이 반영됩니다!

  1. 새로 GitHub에 올릴 때:

    ① 현재 코드를 내 컴퓨터에 index.html 이름으로 저장합니다.
    ② github.com에서 Public 저장소를 생성하고 index.html을 업로드합니다.
    ③ [Settings] → [Pages]에서 Branch를 main으로 선택하고 [Save]를 누릅니다.

  2. 기존 GitHub 저장소의 index.html 덮어쓰기(업데이트):

    ① GitHub 저장소에서 기존 index.html 파일을 클릭하고 우측 상단 연필 아이콘(Edit this file)을 누릅니다.
    ② 기존 내용을 전체 선택(Ctrl+A) 후 삭제하고, 업그레이드된 새 코드 전체를 붙여넣기(Ctrl+V) 합니다.
    ③ 우측 상단 초록색 [Commit changes...]를 누르면 1~2분 내로 GitHub Pages 웹사이트가 자동 업데이트됩니다. (반영 후 Ctrl+Shift+R로 강력 새로고침!)
