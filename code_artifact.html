🚀 GitHub에 업로드하여 나만의 라벨 웹페이지 만들기

이 웹페이지는 별도의 서버나 복잡한 설치 없이 단 하나의 파일(index.html)로 모든 기능이 작동하도록 제작되었습니다. 아래 순서대로 GitHub에 올리시면 무료 웹 주소(URL)가 생성되어 스마트폰이나 PC 어디서든 접속해 라벨을 뽑으실 수 있습니다!

  1. 코드 저장하기:

    현재 코드 편집기의 내용을 복사하거나 다운로드하여 내 컴퓨터에 index.html이라는 이름으로 저장합니다.

  2. GitHub 새 저장소(Repository) 만들기:

    github.com에 로그인한 뒤 우측 상단 [+] → [New repository]를 클릭합니다.
    • Repository name: 예) sool-label 입력
    • Public 선택 후 하단 초록색 [Create repository] 버튼 클릭!

  3. index.html 파일 업로드:

    생성된 화면에서 "uploading an existing file" 링크를 클릭하고, 저장해둔 index.html 파일을 마우스로 끌어다 놓은 뒤 하단의 초록색 [Commit changes] 버튼을 누릅니다.

  4. GitHub Pages(무료 웹 호스팅) 켜기:

    저장소 상단 메뉴의 [Settings] → 좌측 메뉴의 [Pages]로 이동합니다.
    • Branch 항목에서 None을 main으로 바꾸고 [Save]를 클릭합니다.
    • 약 1분 뒤 페이지 상단에 https://내아이디.github.io/sool-label/ 주소가 나타나며, 조원분들과 링크를 공유해 언제든 사용하실 수 있습니다!
